# Simple Calculator

A small command-line calculator written in Python. It was built to practise
Git branching, merging and merge-conflict resolution.

## Features

- Addition, subtraction, multiplication and division
- Division: results are rounded to 2 decimal places, and dividing by zero shows a clear error message

## How to run

    python calculator.py

## How to test

    python -m unittest -v

This repository was used to practise branching, merging and resolving an intentional merge conflict.
